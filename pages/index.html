Respostas só com os seus documentos. Com a página.

O Nexo cria agentes de IA, cada um preso à própria base de conhecimento. Eles conversam com a equipe, atendem clientes pelo WhatsApp e pelo site e respondem a qualquer ferramenta compatível com a OpenAI, sempre citando o trecho e a página. Se a informação não estiver lá, o Nexo diz que não encontrou.

Novidades da 2.4

Fácil de instalar, configurar, manter e integrar.

Do primeiro acesso ao agente publicado no site, tudo pela tela, sem editar arquivos nem reiniciar o servidor.

Como funciona

Quatro passos até o agente no ar.

  1. InstaleBaixe o Nexo-Setup.exe, instale sem administrador e abra pela pesquisa do Windows. A primeira abertura já traz a base e o agente de teste com o Llama 3.1.
  2. AlimenteEnvie PDF, DOCX, EPUB, PPTX, XLSX, CSV, HTML e outros, escreva textos ou importe páginas por link.
  3. Crie o agenteDê nome, instruções, saudação e uma base. Ele só responde com o que estiver nela.
  4. PubliqueConverse pelo chat, conecte o WhatsApp, cole o widget no site ou use a API compatível com OpenAI.
Telas

Integrações

Leve o agente para onde as pessoas estão.

Widget: cole antes de </body>
<script src="https://nexo.suaempresa.com.br/widget.js"
        data-nexo="nxw_SUA_CHAVE_PUBLICA" async></script>

Funciona em qualquer site, no WordPress, no Wix e no Google Tag Manager. Só os sites autorizados mostram o botão.

API compatível com OpenAI
from openai import OpenAI

cliente = OpenAI(base_url="https://seu-nexo/v1", api_key="nxk_...")
resposta = cliente.chat.completions.create(
    model="sofia-suporte",
    messages=[{"role": "user", "content": "Como trocar o filtro?"}],
)

Cada agente vira um modelo. Também há chaves de API com permissão, pergunta direta, streaming e webhooks assinados.

Instalar

Um instalador para Windows. Abra pela pesquisa.

Windows 10 e 11

Baixe o Nexo-Setup.exe, instale e abra o Nexo pelo menu Iniciar ou digitando Nexo na pesquisa do Windows. Para o Llama 3.1, instale o Ollama e rode uma vez:

winget install --id Ollama.Ollama -e
ollama pull llama3.1
Primeiro acesso

O Nexo abre numa janela própria, sem navegador. Entre com admin e Nexo@2026 e escolha uma senha nova. A Base de teste e o Agente de teste já estão prontos em Chats com agentes; o assistente de configuração fica em Sistema e conta.
